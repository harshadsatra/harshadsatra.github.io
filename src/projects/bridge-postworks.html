About the project

Bridge Postworks is a post-production facility offering colour grading, dailies, DCP mastering and HDR services to film and advertising productions. In 2022 Harshad Satra designed the technical architecture and developed the studio's website, built in Nuxt.js with Directus as a headless CMS and deployed on AWS.

A post-production studio sells on picture quality, so the site needed to present showreels and graded work in high fidelity without the slow load times that usually come with heavy video. It also needed to be easy for the studio team to update with new projects and credits without a developer.

Approach

What was built

Nuxt.js front end

A server-rendered Vue.js site, so pages arrive as complete HTML for fast first paint and full indexing by search engines.

Directus headless CMS

A custom data model for projects, credits, services and media, giving the studio a clean admin panel to publish new work.

Custom media streaming player

A purpose-built player for showreels and project clips, with media stored on AWS S3 and streamed on demand instead of loaded upfront.

AWS deployment

The Nuxt app and Directus run on AWS EC2, with S3 handling media storage.
