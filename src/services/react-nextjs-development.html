FAQ

Frequently asked questions

Why build a marketing website in Next.js instead of WordPress?

Next.js sites are faster and more secure by default because most pages are pre-rendered and there is no public admin to attack. It's a good fit when the site will grow into an app, or when content comes from a headless CMS. WordPress is still a great choice for content-heavy sites with large editorial teams.

Can you help with an existing React or Next.js codebase?

Yes. I can review architecture and performance, upgrade to the App Router, fix Core Web Vitals issues, or take over feature development.

Do you also handle design?

I work best from a Figma design. If you don't have one, I can work with a designer I trust or build from a reference site and your brand guidelines.

Where will my Next.js site be hosted?

Usually on Vercel, which is built by the Next.js team, but I also deploy to AWS when a project needs to stay within your existing cloud account.
